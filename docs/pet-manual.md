# Kitty 电子宠物 · 产品说明书

> 面向使用者。想知道怎么实现，看 [`pet-design.md`](pet-design.md)。
> 本文列出她的**全部功能**，并标注每一项当前的实现状态。

状态标记：

| 标记 | 含义 |
| --- | --- |
| ✅ 已有 | 当前固件已经能用 |
| 🚧 V0 / V1 / V2 / V3 / V4 | 规划中，数字是阶段（见 §12） |
| ❌ 不做 | 设计上明确排除 |

> **当前进度**：只有 ✅ 那几项能用。这台设备现在还是一块"会播动画的板子"。

---

## 1. 她是什么

一台放在桌上的 Kitty。她有自己的作息、情绪和体力，会困、会饿、会自己找你。

**不需要网络、不需要账号、不需要激活**。拔掉网线、云端服务下线、公司跑路，她都照常活着。

插上电脑，她可以变成你电脑上 AI agent 的"身体"——agent 在她脸上做表情，用她的嗓子说话，
而她干活会累，需要你去喂、去摸、去让她睡。

到了晚上，她安静下来陪你睡。

她的身体状态，是你和 agent 一起经营出来的。

## 2. 规格

| 项 | 参数 |
| --- | --- |
| 主控 | ESP32-S3R8，8 MB PSRAM |
| 屏幕 | 0.85 英寸，128×128，IPS |
| 声音 | 单麦克风 + 单喇叭（ES8311 + NS4150B） |
| 灯 | 1 颗 RGB 灯珠 |
| 按键 | 2 颗（BOOT、POWER） |
| 触摸 | 无 |
| 摄像头 | 无 |
| 姿态感应 | 无（不能摇晃，不能翻转识别） |
| 网络 | 仅配网用的临时热点；不联网 |
| 供电 | USB；能否脱机使用见 §11 |

## 3. 三种身份

她始终处在三种身份之一，切换是自动的。

| 身份 | 什么时候 | 她会做什么 |
| --- | --- | --- |
| **自主** 🚧 V0 | 默认状态 | 自己过日子：张望、犯困、打哈欠、望着你；数值照常衰减 |
| **充电** 🚧 V1 | 插上 USB，但电脑没接管 | 睡觉、打呼、显示电量；衰减变慢 |
| **被接管** 🚧 V1 | 电脑上的 agent 主动连接并握手 | 表情和声音交给 agent 指挥；你摸她的动作会转告 agent |

> **插电不等于被接管。** 插充电宝、插充电器，她只是在充电；只有电脑上的 agent
> 明确连上来，才会交出控制权。

| 功能 | 说明 | 状态 |
| --- | --- | --- |
| 全屏宠物脸 | 57 帧动画，9 组情绪，铺满整块屏 | ✅ 已有 |
| 呼吸起伏 | 静止时身体轻微起伏，不是一张死图 | 🚧 V0 |
| 眨眼 | 随机间隔，不是定时循环 | 🚧 V0 |
| 情绪表情 | 开心 / 生气 / 困 / 饿 / 蔫 / 撒娇 / 惊讶 / 炸毛 / 睡 | 🚧 V2 |
| 眼神跟随 | 头/眼微微转向你（按键方向或声音方向） | 🚧 V2 |
| 抬头看人 | 有人靠近、被叫名字时抬头 | 🚧 V2 |
| 低数值表现 | 饿了发蔫、脏了掉毛、累了动作变慢 | 🚧 V3 |

## 5. 怎么跟她互动

一共两颗键，所有操作都在这张表里。

| 操作 | 动作 | 状态 |
| --- | --- | --- |
| BOOT 短按 | 摸摸头（加亲密度，有反应） | 🚧 V0 |
| BOOT 双击 | 喂食（加饱食） | 🚧 V3 |
| BOOT 长按 3 秒 | 进入配网模式（开热点） | 🚧 V3 |
| POWER 短按 | 清洁 / 陪玩（自动挑当前最急的一项） | 🚧 V3 |
| POWER 长按 | 进入夜间模式 | 🚧 V3 |
| 叫她的名字 | 有反应（抬头/看过来/应一声） | 🚧 V2 |
| 拍手 / 大声 | 吓一跳（惊讶表情） | 🚧 V2 |

> **误触保护**：双击没判成功时，会退化成一次"摸摸头"——宁可多摸一下，不会误喂。
> 喂多了也不会撑坏，只是浪费。

## 6. 养成：四条数值

她身上有四条数值，都会随时间变化。

| 数值 | 会掉的原因 | 怎么补 | 掉了会怎样 |
| --- | --- | --- | --- |
| **饱食** | 时间流逝；agent 高强度干活 | 喂食 | 表情发蔫、动作变慢 |
| **精力** | 醒着的时间；**agent 每完成一次任务都扣** | 睡觉、插电 | 见底会强制睡着，叫不醒 |
| **清洁** | 时间流逝 | 清洁 | 掉毛、灯色发暗 |
| **亲密度** | 长期不理她；老戳她又不管 | 摸头、陪玩、一起完成任务 | 变冷淡，不再主动凑近你 |

### 成长

养到一定程度会长大，一共三段：

1. **幼体**：动作笨拙、特别爱睡、表情少
2. **成长**：开始主动搭话、解锁新表情
3. **成熟**：表情和音效全解锁，性格稳定

### 她不会死

**没有"养死"这回事。** 长期不管，她只会闹脾气——变冷淡、不理你、数值卡在半死不活的位置。
但认真照顾一次就能拉回来。

一台坏掉的桌面设备没有意义，情绪上的疏远比数值死亡更有效。

## 7. 她自己的日常

你不理她的时候，她不会站着不动。

| 行为 | 触发 | 状态 |
| --- | --- | --- |
| 张望 / 环顾 | 长时间闲置 | 🚧 V2 |
| 哼一声 / 自言自语 | 想引起注意 | 🚧 V2 |
| 伸懒腰 / 舔爪子 | 随机 | 🚧 V2 |
| 打瞌睡 → 睡着 | 精力低 | 🚧 V2 |
| 饿了主动叫 | 饱食低 | 🚧 V3 |
| 亲密度高时主动凑近 | 亲密度高 | 🚧 V3 |
| 声音 | 叫声、哈欠、咕噜、咀嚼（内置短音效，**不会说话**） | 🚧 V2 |

**她不会聊天。** 没有语音识别、没有大模型、不能回答问题。她只会"有反应"。

| 灯的表现 | 含义 | 状态 |

| 暗红 | 生气 / 亲密度低 | 🚧 V2 |

## 10. 和电脑上的 agent 一起用

**什么时候能用**：插上 USB，电脑上的 agent（例如 WorkBuddy）主动连上她。

**你能看到什么**：

| 场景 | 她的表现 | 状态 |
| --- | --- | --- |
| agent 开始干活 | 抬头、转眼睛、灯快速闪 | 🚧 V1 |
| agent 长时间思考 | 抓耳挠腮、东张西望 | 🚧 V1 |
| 任务完成 | 开心表情 + 完成音 + 灯亮一下 | 🚧 V1 |
| 任务失败 / 被打断 | 炸毛表情 + 灯变红 | 🚧 V1 |
| 干活太多 | 精力掉光 → 直接睡着，agent 会收到"我累了" | 🚧 V3 |
| 你摸她一下 | 摸头反应，同时把"被摸"这件事告诉 agent | 🚧 V1 |

**插上线的代价**：她干活会累。agent 用得越凶，你越得伺候她。

**拔线之后**：立刻变回宠物，刚才被 agent 弄掉的状态**原样保留**，不会重置。

## 11. 供电与配网

### 供电

- USB 插电即可用，边用边充
- **能不能脱离 USB 独立跑，取决于这块板子有没有电池接口**（当前未确认）。
  如果没有，脱机使用需要外接移动电源或改硬件

### 配网（用来改参数）

她不需要连 WiFi 上网，热点只用来改设置。

| 步骤 | 操作 | 状态 |
| --- | --- | --- |
| 1 | 长按 BOOT 3 秒，她进入配网模式 | 🚧 V3 |
| 2 | 手机连上她开的热点 | 🚧 V3 |
| 3 | 浏览器打开配置页，改参数 | 🚧 V3 |
| 4 | 保存后热点自动关闭，省电 | 🚧 V3 |

3 分钟没操作也会自动关，不会一直耗电。

### 能改的参数

| 参数 | 说明 | 状态 |
| --- | --- | --- |
| 名字 | 她的名字（唤醒词与界面用） | 🚧 V3 |
| 音量 / 亮度 | 基础设置 | 🚧 V3 |
| 唤醒灵敏度 | 叫名字好不好使 | 🚧 V3 |
| 作息时段 | 几点睡、几点起（决定夜间模式） | 🚧 V3 |
| 性格 | 黏人 / 冷淡 / 活泼 | 🚧 V3 |
| 难度 | 数值掉得快慢：轻松 / 正常 / 硬核 | 🚧 V3 |
| 时间 | 手动对时（没有网络，时间是手动或电脑同步的） | 🚧 V3 |

## 12. 阶段

每个阶段结束时，设备都是可以长期使用的完整状态。

| 阶段 | 内容 | 结束时可用的功能 |
| --- | --- | --- |
| **V0 活着** | 表情层、呼吸眨眼、摸头有反应、数值衰减、掉电存档 | 她是个会动的宠物 |
| **V1 可被接管** | USB 连接、握手、断线回自主、状态继承 | 插电脑能被 agent 驱动 |
| **V2 有脾气 + 会睡觉** | 自主行为、情绪、昼夜、夜间模式、灯、音效、叫名字 | 她有自己的生活 |
| **V3 养成闭环** | 四条数值、手势输入、成长、agent 消耗体力、配网页 | 完整的养成游戏 |
| **V4 扩展** | 音效包、人格档、可选无线、可选多宠物互动 | 平台化 |

## 13. 她不提供的东西

写清楚，免得期待错：

- ❌ 不会聊天、不会回答问题（没有语音识别，没有大模型）
- ❌ 不需要也不会联网（天气、新闻、时间服务都没有）
- ❌ 不能触摸（屏幕不是触摸屏）
- ❌ 不能摇晃（没有姿态传感器）
- ❌ 不会"养死"
- ❌ 没有手机 App
- ❌ 不能多台互相对话（V4 之后可能）

## 14. 常见疑问

**Q：断网了她还能用吗？**
能。她从设计上就不联网，配网热点只是为了改设置。

**Q：云端服务方跑路了呢？**
没有影响。她完全跑在设备本地。

**Q：她会不会很费电？**
配网热点只在改设置时开 3 分钟，平时关闭。夜间白噪音要连续放 6–8 小时，
功放发热与耗电需要实测——这是当前未解决的项。

**Q：多久要照顾一次？**
取决于难度设置。默认下一两天不理她，她会明显变冷淡，但不会死。

**Q：agent 干活太狠会怎样？**
精力掉光她会直接睡着。这是设计的一部分：她的体力约束 agent 的用法。

**Q：能不能只当宠物，不接电脑？**
能。插不插电脑都是同一台设备，接电脑只是多一层能力。
