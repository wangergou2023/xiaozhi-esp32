# Kitty 电子宠物 · 产品说明书

> 面向使用者。想知道怎么实现，看 [`pet-design.md`](pet-design.md)。
> 本文列出她的**全部功能**，并标注每一项当前的实现状态。

状态标记：

| 标记 | 含义 |
| --- | --- |
| ✅ 已有 | 当前固件已经能用 |
| 🚧 V0 / V1 / V2 / V3 / V4 | 规划中，数字是阶段（见 §12） |
| ❌ 不做 | 设计上明确排除 |

> **当前进度**：V0「活着」已经落地 —— 她有自己的四项数值、会呼吸会眨眼、会自己找点事做，
> 摸她会回应，数值掉电不丢。下面标 ✅ 的都能用；标 🚧 的还没有。

## 1. 她是什么

一台放在桌上的 Kitty。她有自己的作息、情绪和体力，会困、会饿、会自己找你。

**不需要网络、不需要账号、不需要激活**。拔掉网线、云端服务下线、公司跑路，她都照常活着。

插上电脑，她可以变成你电脑上 AI agent 的"身体"——agent 在她脸上做表情，用她的嗓子说话，
而她干活会累，需要你去喂、去摸、去让她睡。

到了晚上，她安静下来陪你睡。

她的身体状态，是你和 agent 一起经营出来的。

| 供电 | USB；能否脱机使用见 §11 |

## 3. 开机与第一次使用

### 开箱到能用（约 5 分钟）

| 步骤 | 做什么 | 你会看到 | 状态 |
| --- | --- | --- | --- |
| 1 | USB 线插电脑或充电器 | 开机动画，宠物脸出现 | ✅ 已有 |
| 2 | 等她几秒，让她醒过来 | 眨眼、打量四周 | ✅ 已有 |
| 3 | 长按 BOOT 3 秒进配网 | 屏幕盖上一块小黑板，写着热点名和 192.168.4.1 | ✅ 已有 |
| 4 | 手机连热点（密码 kitty1234），打开 192.168.4.1 | 一组参数表单 | ✅ 已有 |
| 5 | **至少设置时间** | 保存后热点自己关掉，回到宠物画面 | ✅ 已有 |
| 6 | 拔线（若有电池）或留着插电 | 开始过她自己的日子 | ✅ 已有 |

> **时间必须设。** 她靠时间判断早晚、决定什么时候睡。没有时间，夜间模式不会启动，
> 其余功能不受影响。

### 头十分钟建议这么玩

1. 摸摸头（BOOT 短按），看她怎么回应
2. 叫她的名字，看她抬不抬头
3. 喂一口（BOOT 双击），看她吃不吃
4. 等着，别理她两分钟——看她会不会自己找点事做

## 4. 屏幕上会看到什么

整块 128×128 的屏幕**只有她的脸**。没有状态栏、没有文字、没有图标、没有进度条。

这是刻意的设计：一块 0.85 寸的屏，塞进数字和文字就不像宠物，像仪表盘。

### 她不显示数字

| 你关心的 | 她怎么告诉你 | 状态 |
| --- | --- | --- |
| 饿不饿 | 表情发蔫、主动叫、盯着你看 | 🚧 V3 |
| 累不累 | 动作变慢、频繁打哈欠、眼皮沉 | 🚧 V3 |
| 脏不脏 | 毛发帧变化、灯色变暗 | 🚧 V3 |
| 喜不喜欢你 | 主动凑近（高）／躲开视线（低） | 🚧 V3 |
| 电量 | 低电时脸上出现极简电池符号 | 🚧 V3 |

**要精确数值，插电脑让 agent 读。** 说明书不给她加数值界面，是因为看得见的数字会让人
盯着数字玩，而不是看着她。

### 会短暂盖住脸的东西

只有三种，都极简、都会自动消失：

- 配网时的热点名与地址（黑底两行小字，仅配网期间，✅ 已有）
- 低电电池符号
- 被 agent 接管的短暂指示（一下）

## 5. 三种身份

她始终处在三种身份之一，切换是自动的。

| 身份 | 什么时候 | 她会做什么 |
| --- | --- | --- |
| **自主** ✅ 已有 | 默认状态 | 自己过日子：张望、犯困、打哈欠、望着你；数值照常衰减 |
| **充电** ✅ 已有 | 插上 USB，但电脑没接管 | 慢慢回精力，别的衰减变慢 |
| **被接管** ✅ 已有 | 电脑上的 agent 主动连接并握手 | 表情交给 agent 指挥；你摸她的动作会转告 agent；3 秒没心跳就交还 |

> **插电不等于被接管。** 插充电宝、插充电器，她只是在充电；只有电脑上的 agent
> 明确连上来，才会交出控制权。

## 6. 她会做的表情与动作

| 功能 | 说明 | 状态 |
| --- | --- | --- |
| 全屏宠物脸 | 57 帧动画，9 组情绪，铺满整块屏 | ✅ 已有 |
| 呼吸起伏 | 静止时身体轻微起伏，不是一张死图 | ✅ 已有 |
| 眨眼 | 随机间隔，不是定时循环 | ✅ 已有 |
| 情绪表情 | 九组动作 + 速度 + 灯色组合出开心 / 蔫 / 困 / 睡 | ✅ 已有 |
| 眼神跟随 | 头/眼微微转向你（按键方向或声音方向） | 🚧 V2 |
| 抬头看人 | 有人靠近、被叫名字时抬头 | 🚧 V2 |
| 低数值表现 | 饿了发蔫、累了动作变慢、脏了灯变暗 | ✅ 部分（发蔫和变慢有，掉毛帧没有） |
| 暗色主题 | 夜间与默认两套配色 | ✅ 已有 |

### 这些表情是怎么来的

- 一共 **57 帧**，分 **9 组动作**（各组帧数：6 / 8 / 8 / 4 / 5 / 8 / 6 / 6 / 6）
- 注意：这九组是**动作**（待机、转身、跑动、挥手、跳、蔫、张望、端详），不是九张不同的脸 ——
  素材里没有"生气脸""睡觉脸"这种东西。情绪是靠挑哪一组动作、多快、配什么灯来表达的
- 每帧 **88×128**，RGB565 格式，合计约 **1.28 MB**，直接编译进固件
- 面板是方的（128×128），画面旋转是在生成帧的时候做好的，不是屏幕上转
- 选哪一组：先看服务端（或本地情绪）判定，其次看设备状态

新增一组情绪就要重新算 Flash 预算，不是随手加一条。

## 7. 怎么跟她互动

一共两颗键，所有操作都在这张表里。

| 操作 | 动作 | 状态 |
| --- | --- | --- |
| BOOT 短按 | 摸摸头（加亲密度，有反应） | ✅ 已有 |
| BOOT 双击 | 喂食（加饱食） | ✅ 已有 |
| BOOT 长按 3 秒 | 进入配网模式（开热点） | 🚧 V3（现在只有一下表情反馈） |
| POWER 短按 | 清洁 / 陪玩（自动挑当前最急的一项） | 🚧 键还没接（见设计文档未决项 1） |
| POWER 长按 | 进入夜间模式 | 🚧 键还没接 |
| 叫她的名字 | 有反应（抬头/看过来/应一声） | 🚧 链路已通，真人识别率待验证 |
| 拍手 / 大声 | 吓一跳（转头看你 + 一声叹气） | ✅ 已有 |

> **误触保护**：双击没判成功时，会退化成一次"摸摸头"——宁可多摸一下，不会误喂。
> 喂多了也不会撑坏，只是浪费。

## 8. 养成：四条数值

她身上有四条数值，都会随时间变化。**V0 已经把四条数值、衰减和掉电存档做出来了**，
下面这张表就是现在跑在设备里的规则（衰减速率见设计文档 §6）。

| 数值 | 会掉的原因 | 怎么补 | 掉了会怎样 |
| --- | --- | --- | --- |
| **饱食** | 时间流逝；agent 高强度干活 | 喂食 | 表情发蔫、动作变慢 |
| **精力** | 醒着的时间；**agent 每完成一次任务都扣** | 睡觉、插电 | 见底会强制睡着，叫不醒 |
| **清洁** | 时间流逝 | 清洁 | 掉毛、灯色发暗 |
| **亲密度** | 长期不理她；老戳她又不管 | 摸头、陪玩、一起完成任务 | 变冷淡，不再主动凑近你 |

### 成长

养到一定程度会长大，一共三段（阶段会真的改变她的行为）：

1. **幼体**：只会张望和打瞌睡，动作少
2. **成长**：多一个伸懒腰
3. **成熟**：加上突然雀跃一下


1. **幼体**：动作笨拙、特别爱睡、表情少
2. **成长**：开始主动搭话、解锁新表情
3. **成熟**：表情和音效全解锁，性格稳定

### 她不会死

**没有"养死"这回事。** 长期不管，她只会闹脾气——变冷淡、不理你、数值卡在半死不活的位置。
但认真照顾一次就能拉回来。

一台坏掉的桌面设备没有意义，情绪上的疏远比数值死亡更有效。

| 行为 | 触发 | 状态 |

| 张望 / 环顾 | 长时间闲置 | ✅ 已有 |
| 哼一声 / 自言自语 | 想引起注意 | 🚧 V2（要音效） |

## 12. 和电脑上的 agent 一起用

这是她的第二重身份：**电脑上 AI agent 的身体**。

插上 USB，agent 借她的脸和嗓子；她干活会累，你得伺候她。

### 10.1 怎么连（三步）

| 步骤 | 发生什么 | 她的反应 | 状态 |
| --- | --- | --- | --- |
| 1 | USB 线插上电脑 | 进入"充电态"，**还没交权**，只是打瞌睡 | ✅ 已有 |
| 2 | agent 打开串口，发 `pet.hello` | 灯色和脸交给 agent | ✅ 已有 |
| 3 | agent 断开 / 拔线 / 3 秒没心跳 | 愣一下，回到自主模式 | ✅ 已有 |

**钥匙在 agent 手里。** 插充电器、插充电宝，她只是充电；只有 agent 主动握手，才交出控制权。

agent 还负责两件事：`pet.time` 把时间对给她（她没有 RTC，也没有网络），
`pet.night` 手动让她进/出夜间模式。没对时的话，作息时段不会自动生效。

### 10.2 什么程序能连

| 程序 | 能不能 | 说明 | 状态 |
| --- | --- | --- | --- |
| 任意脚本 | ✅ | 任何能打开串口、按行收发 JSON 的语言（Python、Node、Go…） | ✅ 已有 |
| agent 框架（如 WorkBuddy） | ✅ | 同上，不需要专门适配库 | ✅ 已有 |
| MCP 客户端 | ✅ | 协议就是 MCP 那套 JSON-RPC 格式 | ✅ 已有（行式 JSON-RPC，不是 stdio 传输） |
| 手机 App | ❌ | 不做 | ❌ |
| 浏览器直接连 | ❌ | 需要本地中间层 | ❌ |
| 网络远程控制 | ❌ | 她不联网，没有暴露端口 | ❌ |

**不需要装驱动**，插上就是这个系统里多出来的一个串口。

### 10.3 agent 能让她做什么

| 能力 | 效果 | 限制 | 状态 |
| --- | --- | --- | --- |
| 换表情 | 指定情绪和强度 | 只能选预设的那几组，不能任意画 | ✅ 已有 |
| 说话 | agent 把音频推过来，她张嘴放 | 有缓冲，不是低延迟对讲 | 🚧 还没做（调 `pet.say` 会返回错误） |
| 看向某处 / 抬头低头 | 整张脸平移几个像素 | 幅度有限（±8 px），屏幕就这么大 | ✅ 已有 |
| 读状态 | 拿到四条数值、模式、成长阶段 | 电量要等硬件确认 | ✅ 已有 |
| 上报事件 | 你摸她、她累了、数值变了 | 只推这几类 | ✅ 已有 |
| 代她照顾 | agent 也能喂、清洁、陪玩 | **有上限**：代劳只补一半，且补到 85 就补不动了 | ✅ 已有 |
| 让她睡 / 叫醒 | 强制入睡或唤醒 | 精力见底时叫不醒 | ✅ 已有 |

### 10.4 agent 不能让她做什么

她不是显示器，也不是音箱。这几条是硬边界：

- ❌ 不能任意绘制画面——只能选表情组
- ❌ 不能自定义新动作——只有那套动作原语
- ❌ 不能解锁数值上限、不能删档
- ❌ 不能在夜间持续输出（防半夜被吵醒）
- ❌ 不能绕过"累了就睡"——精力见底，agent 说什么都没用

最后一条是设计核心：**她的体力约束 agent 的用法**，而不是 agent 无限压榨她。

### 10.5 她会主动告诉 agent 的事

| 事件 | 什么时候 | 状态 |
| --- | --- | --- |
| 被摸了 | `pet.poke`，你按她 | ✅ 已有 |
| 我饿了 | 饱食低于阈值 | 🚧 V3 |
| 我累了 | `pet.tired`，精力低于 15 | ✅ 已有 |
| 我醒了 | 夜间结束 / 被叫醒 | 🚧 V3 |
| 电量低了 | 未接电且电量低 | 🚧 V3 |
| 有人吵我 | 夜间被按键或声音惊动 | 🚧 V3 |

### 10.6 你在桌面上看到的样子

| 场景 | 她的表现 | 状态 |
| --- | --- | --- |
| agent 开始干活 | 抬头、东张西望（`pet.face` / `pet.look`） | ✅ 已有 |
| agent 长时间思考 | 抓耳挠腮、东张西望 | 🚧 V1 |
| 任务完成 | `pet.task result=done` → 开心动作，精力 −5 | ✅ 已有（无音效） |
| 任务失败 / 被打断 | `pet.task result=error` → 蔫下去，精力 −8 | ✅ 已有（无音效） |
| 连续干了很多活 | 表情越来越蔫 → 直接睡着 | 🚧 V3 |
| 你摸她一下 | 摸头反应，同时 `pet.poke` 推给 agent | ✅ 已有 |
| 她睡着了 agent 还在派活 | 叫不醒，agent 收到"我累了" | 🚧 V3 |

### 10.7 插上线的代价

她干活要花体力。agent 用得越凶，你越得伺候她（这几条已经在跑）：

| agent 做了什么 | 她付出什么 |
| --- | --- |
| 完成一次任务 | 精力 −5，亲密度 +2 |
| 报错 / 被打断 | 精力 −8，亲密度 −1，炸毛 |
| 长时间思考 | 精力缓慢下降，表情焦躁 |
| 精力见底 | 强制睡着，拒绝一切请求 |

### 10.8 拔线与独占

**拔线之后**：立刻变回宠物（3 秒没心跳也算断线）。被 agent 弄掉的数值**原样保留**，不会重置——
她记得刚才干了什么。

**独占**：她只有一条串口。当前规则是先到先得，第二个程序要等第一个断开。

> 未决：要不要支持新连接抢占旧连接？以及音频缓冲带来的实际延迟是多少——两者都要真机测试后才能定。

## 13. 供电与充电

### 怎么供电

| 情况 | 她的状态 | 状态 |
| --- | --- | --- |
| USB 接电脑，agent 未接管 | 充电态，打瞌睡 | 🚧 V1 |
| USB 接充电器 / 充电宝 | 充电态，打瞌睡 | 🚧 V1 |
| 不接 USB（若有电池） | 完全自主，正常过日子 | 🚧 V0 |

> **能不能脱离 USB 独立跑，取决于这块板子有没有电池接口**（当前未确认）。
> 没有的话，脱机使用需要外接移动电源或改硬件。

### 电量怎么表现

| 电量 | 她会怎样 | 状态 |
| --- | --- | --- |
| 充电中 | 脸上偶尔闪过充电符号，睡得香 | 🚧 V3 |
| 满电 | 无特殊表现 | 🚧 V3 |
| 低电 | 脸上出现极简电池符号，动作变慢，灯变暗 | 🚧 V3 |
| 极低 | 自己睡着省电，醒来后更蔫 | 🚧 V3 |

### 耗电预期

| 场景 | 说明 | 状态 |
| --- | --- | --- |
| 待机（自主模式） | 屏常亮 + 偶尔出声；具体续航需实测 | 🚧 V0 |
| 夜间模式 | 屏极暗 + 连续白噪音 6–8 小时，功放发热与耗电**未实测** | 🚧 V2 |
| 配网模式 | 热点只开 3 分钟，之后关闭 | 🚧 V3 |

> 功耗数据目前全是空白。这是要先测的第一件事，否则"脱机用一整天"这个承诺不能写。

## 15. 固件升级

她**没有云端 OTA**，升级只有一条路：插 USB 烧录。

| 步骤 | 做什么 | 状态 |
| --- | --- | --- |
| 1 | USB 连电脑，装好 ESP-IDF 环境 | ✅ 已有 |

| 3 | `idf.py -p <串口> flash` | ✅ 已有 |
| 4 | 重启，她还记得自己几岁、饿不饿 | ✅ 已有 |

**数值存档在另一块存储区，正常升级不会清掉她。** 但如果遇到存档格式变更的大版本，

没有云端，好处是没有"服务器关了就不能升级"这回事；坏处是你得自己动手。

## 16. 故障排查

按这张表先自查，再决定要不要拆。

| 现象 | 可能原因 | 怎么办 | 状态 |
| --- | --- | --- | --- |
| 插上没反应 | 线是纯充电线，或供电不足 | 换一条数据线 / 换 USB 口 | ✅ 已有 |
| 屏幕亮但脸不动 | 动画帧没加载 | 重新烧录固件 | ✅ 已有 |
| 屏幕花屏、边缘有彩条 | 面板窗口偏移不对 | 需要 `DISPLAY_OFFSET_X/Y` 修正 | ✅ 已有 |
| 没声音 | 音量 0、功放没使能、喇叭接触不良 | 先调音量，再查 PA 引脚 | 🚧 V2 |
| 叫名字没反应 | 灵敏度太低，或环境太吵 | 调高灵敏度 | 🚧 V2 |
| 插电脑没反应 | agent 没握手，只是充电态 | 看 §12.1 的连接三步 | 🚧 V1 |
| agent 连上了但她不理 | 精力见底，她睡着了 | 去喂、去让她睡够 | 🚧 V3 |
| 配网搜不到热点 | 没进配网模式，或 3 分钟超时了 | 重新长按 BOOT | ✅ 已有 |
| 时间不对 | 没对过时 | 重新配网设时间，或插电脑让 agent 同步 | 🚧 V3 |
| 数值不涨 | 可能到了上限，或难度太高 | 调难度、看是不是喂满了 | ✅ 已有 |
| 她一直睡 | 精力低、夜间模式、或没电 | 按一下 BOOT 就能叫醒；再查精力 | ✅ 已有 |

## 19. 她不提供的东西

- ❌ 没有手机 App

## 20. 常见疑问

### 关于联网与云端

**Q：断网了她还能用吗？**
能。她从设计上就不联网，配网热点只是为了改设置。

**Q：云端服务方跑路了呢？**
没有影响。她完全跑在设备本地，没有激活、没有账号、没有远程依赖。

**Q：为什么不做云端大模型对话？**
因为那样一来，服务器一停她就变砖。她的嘴用来叫、不是用来聊天的。

### 关于照顾

**Q：多久要照顾一次？**
取决于难度设置。默认难度下，一两天不理她会明显变冷淡，但不会死。

**Q：她会不会死？**
不会。没有养死机制。长期不管，她只是闹脾气——变冷淡、不理你、数值卡在半死不活。
认真照顾一次就能拉回来。

**Q：能不能开挂/改存档？**
能，数值存在设备里，但说明书不教。

**Q：agent 干活太狠会怎样？**
精力掉光她直接睡着，agent 说什么都没用。这是设计的一部分：她的体力约束 agent 的用法。

### 关于硬件

**Q：能不能只当宠物，不接电脑？**
能。插不插电脑都是同一台设备，接电脑只是多一层能力。

**Q：她会不会很费电？**
待机功耗、夜间白噪音的连续播放功耗（6–8 小时）目前都没实测。这是当前最该先测的数。

**Q：屏幕能换成大的吗？**
不能。表情帧是按 88×128 生成的，换屏要重做全部动画。

**Q：能不能加触摸？**
硬件没有触摸屏。要触摸得换屏，等于换一台设备。

**Q：能不能摇晃她？**
没有姿态传感器，摇不动。

**Q：她坏了怎么办？**
先看 §16 故障排查。软件问题重烧固件；硬件问题（不亮、不响、不充电）得拆。

### 关于开发与升级

**Q：怎么升级固件？**
插 USB 烧录，没有云端 OTA。正常升级不会清掉她的数值，见 §15。

**Q：能装自己的表情包吗？**
V4 之后可能，需要重新生成帧数据并重烧。现在只能改代码。

**Q：能不能同时接两个 agent？**
不能。只有一条串口，先到先得，第二个要等第一个断开。
